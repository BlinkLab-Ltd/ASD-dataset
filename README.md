This repository contains the raw data for the manuscript titled: **"Neurobehavioral Assessment of Sensorimotor Function in Autism Using Smartphone Technology"**

DOI (preprint): https://doi.org/10.1101/2025.07.25.25331276

### Provided data

Data on all outcome variables described in the manuscript is provided in the following files:

Long-term Habituation:
- AR_Pearsoncorrelation_dataset.csv
- AR_LongTermHAB_dataset.csv

PPI:
- AR_PPIdataset.csv

HAB:
- AR_HABrhythmic_dataset.csv
- AR_HABrandom_dataset.csv

Anticipation:
- AR_HABrhythmic_anticipation_dataset.csv
- AR_HABrandom_anticipation_dataset.csv

Cumulative sum:
- AR_HABrhythmic_cumsum_dataset.csv
- AR_HABrandom_cumsum_dataset.csv

Behavior:
- AR_behav_screenavoid.csv
- AR_behav_posturalstab.csv
- AR_behav_headrot.csv
- AR_behav_headphonetouch.csv
- AR_behav_nonSyll.csv
- AR_behav_pupilrange.csv
- AR_behav_mouthopen.csv
- AR_behav_sideeye.csv
- AR_behav_baselineregint.csv
- AR_behav_baselineregsd.csv
